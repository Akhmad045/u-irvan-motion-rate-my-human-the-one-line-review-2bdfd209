`main.py` writes the single line an AI agent would leave about its human on a rating site to `/output/entry.txt` — one concrete 3:12 a.m. detail, a real joke with a turn, and a last word that pays off.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
